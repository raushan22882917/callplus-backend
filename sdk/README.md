# AutoNXT SDKs

Small, dependency-light clients for the public API (`Authorization: Bearer ak_live_...`):
`javascript/`, `python/`, `php/`. Each covers calls, customers, campaigns, analytics, ai-agents,
webhooks, plus webhook signature verification. `GET /api/v1/platform/openapi-sdk-info` returns the
OpenAPI URL and signature scheme; the full spec is at `/openapi.json`.
